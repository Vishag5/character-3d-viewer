# 3D Character Web Viewer

Interactive 3D model viewer web application powered by Google `<model-viewer>`.

## Features
- **3D Orbit & Zoom Controls**: Smooth 360-degree rotation and zoom.
- **Animation Controls**: Dynamic buttons for available animations (`Idle`, `Wave`) + Play/Pause toggle.
- **Augmented Reality (AR)**: WebXR, Quick Look (iOS USDZ / AR preview), and Scene Viewer (Android).
- **Auto-rotation**: Seamless 360 rotation with user-controlled toggle.
- **Zero Configuration**: Ready to host on GitHub Pages.
